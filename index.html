Результаты

Файлы не выбраны
После загрузки здесь появятся сведения о чертеже и ссылки на исправленные версии.

Исправленный DXF

Сохраняет все исходные объекты и их DXF-версию. Корректирует границы чертежа EXTMIN / EXTMAX. Самый осторожный вариант, но не лечит любые ошибки файла.

DXF AutoCAD 2000

AutoCAD 2000 сохраняет линии, полилинии и MTEXT. Режим R12 пока отключён, чтобы не создавать некорректные файлы. AutoCAD 2000 работает с полноценной структурой DXF и сохраняет многострочный текст.

Как открыть после конвертации
  1. Скачай «AutoCAD 2000» и открой его в AutoCAD через команду OPEN.
  2. Если чертёж не виден, введи ZOOM и затем E.
  3. Проверь чертёж и командой SAVEAS сохрани в DWG.
  4. AutoCAD R12 в этой версии отключён. Если новый DXF не открылся, попробуй «Исправленный исходный DXF».

Все файлы обрабатываются только внутри браузера: содержимое чертежей никуда не отправляется. Утилита не заменяет AutoCAD и не может гарантировать исправление любого DXF. Перед работой с ответственным чертежом проверь число объектов и координаты в CAD.

Высоты Lixel Studio → блоки M1502

Загрузи TXT, CSV, TSV, XYZ, PTS, ASC или DAT. Программа создаст один блок M1502 на каждую точку с редактируемым атрибутом HEIGHT и скрытыми данными MARK / NAME.

Колонки исходного файла

Если порядок координат отличается, выбери нужные столбцы вручную. Никаких координат не округляю при создании точек.

Настройки чертежа DXF

Обычно в экспорте Lixel координаты уже абсолютные. Не включай offset без проверки. Для совмещения с существующим чертежом на уровне Z = −21.659 можно ввести это значение выше в режиме 2D.

Предпросмотр точек


    

  

  

   
Блоки M1502 вместо TEXT
Все точки записываются как INSERT M1502 на слое M1502. У каждого блока атрибуты HEIGHT (видимая отметка), MARK и NAME (по умолчанию скрыты).

   
Точность сохраняется
Координаты X/Y и высоты Z в 3D сохраняются без округления. В 2D исходная Z дополнительно хранится в расширенных данных блока (LIXEL_SOURCE). Выбор 2/3 знаков меняет только атрибут HEIGHT.

  

  
Как перенести точки в существующий DWG
  1. Выбери 2D, если работаешь в плане, или 3D для точек с исходной высотой.
  2. Скачай DXF и открой в AutoCAD. Выбери одну отметку: в свойствах должно быть Block Reference, имя M1502. Командой EATTEDIT можно изменить атрибут HEIGHT.
  3. Чтобы перенести в свой чертёж: COPYBASE с базой 0,0,0 → выделить все → в основном DWG PASTECLIP в 0,0,0. Проверь WCS и одинаковые единицы (метры).
  4. Для отображения номеров выбери режим «Показывать в блоке» до экспорта.

  
Без загрузки файлов на сервер. Блок M1502 создаётся с правильными именем и атрибутами HEIGHT / MARK / NAME, но его упрощённый графический символ может отличаться от официальной библиотеки GEOMAVAT. Для точного соответствия офисному шаблону нужен исходный блок M1502. Перед сдачей карты проверь несколько точек в AutoCAD.

Leica GSI → опорные точки Lixel Studio
Загрузи текстовый GSI. Программа извлечёт имена и координаты точек, уберёт дубли и создаст CSV/TXT без заголовка для Map Fusion → Coordinate Transformation.

Формат Lixel Studio
Файл создаётся без заголовка в порядке Point,Easting,Northing,Elevation, например A1,180680.145,647434.147,35.766.

  

  
Как использовать в Lixel Studio
  1. Загрузи GSI и проверь первые координаты в предпросмотре.
  2. Если есть более точные внешние координаты контрольных точек, вставь их в поле выше.
  3. Скачай CSV.
  4. В Lixel Studio открой Project Processing → Map Fusion → Coordinate Transformation и загрузи файл опорных точек.
  5. Перед трансформацией проверь совпадение имён точек и остаточные ошибки.

  
Все вычисления выполняются локально в браузере. По умолчанию используется масштаб ÷1000, проверенный на твоём Leica GSI. Если другой прибор экспортирует другой масштаб, его можно переключить вручную.
